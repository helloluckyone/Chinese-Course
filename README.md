# Mandarin Path — PWA starter

A no-login, static progressive web app for adult English speakers learning Mandarin Chinese. Includes 11 level shells (0–10), short lessons, vocabulary picture cues, tone-marked Hanyu Pinyin, model sentences, browser-generated speech, quick checks, level tests, progress saving, and a service worker for offline app files.

## Publish with GitHub Pages
1. Unzip this folder.
2. Create a public GitHub repository (for example `mandarin-path`).
3. Upload **the contents of this folder** to the repository root (so `index.html` is at the root).
4. In repository Settings → Pages, choose deploy from branch, select `main` and `/(root)`, then Save.
5. Wait for the published HTTPS URL. Open it on your phone/tablet once while online.
6. iPhone/iPad: open the URL in Safari → Share → Add to Home Screen. Android: browser menu → Install app / Add to Home screen.

## Honest prototype limitations
- This is a starter prototype, not yet a complete HSK-aligned or B2-certified course. Each level currently has three sample lessons and a short multiple-choice check; content needs expert review and expansion before representing B2.
- Picture cues are emoji illustrations, not a separate photograph/illustration for every word or scene.
- Audio is generated by the device's text-to-speech engine, not bundled native-speaker recordings. Voice quality and offline availability vary by device/browser. The app works offline after its files are cached, but TTS may need connectivity or a locally installed Chinese voice.
- Speaking recording uses the browser microphone API and HTTPS permission. It lets learners replay themselves but does not provide automatic pronunciation scoring.
- Progress is stored in localStorage on that browser/device. It does not sync between devices; clearing site data removes progress.
- This app teaches simplified characters and Mandarin (Putonghua) using Hanyu Pinyin. Ask a Mandarin teacher to review the content, tones, examples and cultural usage before public release.
